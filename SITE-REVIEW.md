## How to Use This

1. **Make a copy** of this file and add your name to the file name, for example `SITE-REVIEW-jane.md`.
2. **Open each link.** It jumps straight to that spot on the live site and outlines it. Items inside a popup open the popup for you.
3. **Check the box** next to each item you review, then mark `Correct as written` or `Needs a change` (put an `x` in the brackets: `[x]`). Add corrections or comments on the `Notes:` line. Skip anything you are not sure about.
4. **Add any other feedback** in the page-by-page and general sections at the bottom. Short notes are perfect.
5. **Email your copy back** to the site lead. Every reviewer's file will be combined before the next update.

Do as much or as little as you like. Every comment helps.
