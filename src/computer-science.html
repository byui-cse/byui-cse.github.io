What You Will Build

From Your First Program to Systems That Scale

Anyone can make code run. Computer scientists make it fast, make it smart, and prove it is right.

Algorithms That Scale

Master searching, sorting, graph algorithms, and Big O analysis, and prove exactly why one approach beats another.

CSE 381 Algorithms & Complexity

Programs That Do Many Things at Once

Write multithreaded, parallel code that splits huge jobs across many processors, the same way streaming services, search engines, and large-scale data systems work.

CSE 351 Parallelism & Concurrency

Data and Machine Learning

Wrangle real data with Python and SQL, find the patterns hiding in it, and build, train, and evaluate machine learning models.

DS 250 Data Science Programming, Machine Learning

Smart Data Structures

Hash tables, trees, graphs, and design patterns: Organize information so a program stays fast whether it serves ten users or ten million.

CSE 212, CSE 382 Patterns & Data Structures

Products with a Real Team

Gather requirements, design the interface, write and review code, test, and deploy a product together, exactly the way professional software teams do.

CSE 199R Freshman Discovery Project, CSE 399R Product Development Project

Your Own Advanced Focus

How You Will Learn

Understand It First. Then Use Every Tool Well.

You learn programming from the ground up, so you can read any codebase, debug it, reverse engineer how it works, and tell the moment something is wrong. You also study how intelligent systems are built: How they work, where they fail, and how to build them responsibly. Then you use them as one tool among many.

Most courses ask you to explain your thinking, test your work, and build with others. Those are exactly the habits employers and graduate schools look for, and they are what make you hard to replace.
