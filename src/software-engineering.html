Four Ways to Be a Software Engineer

Everyone learns the core: Programming, teamwork, databases, and shipping a real product. Then you choose where to go deep.

Software Design

Design Systems Built to Last

The apps on your phone are millions of lines of code built by hundreds of engineers. Master object-oriented design, design patterns, and software architecture so it keeps growing without falling apart.

Courses include CSE 130, CSE 230, CSE 331 Design Patterns, CSE 430 Architectural Design, and a two-part senior project.

Leads To: Software developer, software engineer, software architect

Full Stack Web Development

Build the Whole Web App

Design the UI people see and click, then build the APIs, servers, and databases that power it. By the end, you can launch a complete web product yourself.

Courses include WDD 231 Web Frontend Development, CSE 340 Web Backend Development, WDD 331R Advanced CSS, WDD 360 Full Stack Foundations, and WDD 430.

Leads To: Web developer, front-end or back-end developer, full stack engineer

Embedded Systems

Put Code inside Real Machines

Cars, smartwatches, and medical devices all run on code someone had to write. Program microcontrollers in C, work with digital logic and computer architecture, and make real machines move, sense, and respond.

Courses include CSE 121C C Language, ECEN 240 Digital Systems, ECEN 260 Microprocessor-Based System Design, ECEN 324 Computer Architecture, and ECEN 361 Embedded Systems.

Leads To: Embedded systems developer, real-time software developer, firmware engineer

Quality Assurance

Make Sure Nothing Breaks

Be the reason an app works perfectly on launch day. Write automated tests, hunt down security vulnerabilities, run UX research with real users, and help lead the team that ships it.

Courses include CSE 270 Software Testing, CSE 372 Requirements Elicitation, CSE 453 Computer Security, CSE 471 UX Research, and BUS 309 Project Management.

Leads To: QA engineer, automation engineer, software test engineer

How You Will Learn

Engineers Own the Result.

Software engineering is a team sport. You will interview users to gather requirements, sketch the UI/UX, plan the architecture, write clean code your teammates can review, automate the tests, and deploy on time. You practice all of it in team courses and a product project long before your internship.

Along the way, you put modern tools to work, including AI for gathering requirements, automating tests, and tuning complex systems. You also learn the engineering standards that keep people in charge of what gets built and responsible for how it works.
