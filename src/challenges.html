Hardware

Circuit Builder

Six levels. Flip the switches, pick a gate, and watch the truth table check every combination. The last level is the circuit that adds numbers inside every processor.

Practice: Logic gates, truth tables, and how hardware computes

Skills You Are Practicing

  • Logic Gates
  • Truth Tables
  • Binary Addition

You learn how gates become processors in ECEN 106 Computer Systems, and the logic behind truth tables in CSE 280 Discrete Mathematics.

How Computers Think

Flip the Bits

Six levels. Each switch is one bit worth double the switch to its right. Make the target number, then spell letters the way a computer stores them.

Practice: Binary and how computers store information

Skills You Are Practicing

  • Binary
  • Place Value
  • Text Encoding

You meet binary from day one in CSE 110 Introduction to Programming and see how hardware stores it in ECEN 106 Computer Systems.

Turn on JavaScript to play this puzzle.
