What You Just Learned

One Number Repainted the Whole Page

What You Just Did

When you moved the slider, a small program took your number, calculated a new set of colors, and swapped them into the page while you watched.

The Idea behind It

  • Variables and Events: The page listens for you to move the slider and stores your choice in a variable.
  • Color Math: Every color is calculated so text stays readable at every level, from 1% to 100%.
  • Saving a Preference: Your browser remembers your setting for the next visit.
  • Accessibility: The program checks contrast so people with low vision can still read the page.

Where You Would Learn This

CSE 110 Introduction to Programming, WDD 130 Web Fundamentals, and WDD 131 Dynamic Web Fundamentals, all in your first two semesters.

Your Ideas. Your Hands. Your Name on It.

We Make Real Things.

You decide what to build. You design it, program it, test it, and ship it, and real people use it. Every decision is yours, and so is the result. Here is the kind of work you will do, from your first semester to your senior project.

Apps and Websites

Design the user interface, build the APIs and database behind it, and deploy the whole stack. You launch your first website your first semester.

Code inside Real Devices

Cars, medical equipment, and smart gadgets all run on firmware someone had to write. Program microcontrollers, read sensors, and make hardware respond in real time.

Security

Reverse engineer systems, run penetration tests, and patch vulnerabilities before an attacker finds them. Sharpen your skills with the Society of Cybersecurity.

Data and Machine Learning

Clean raw data with Python and SQL, train machine learning models, and learn how intelligent systems work from the inside out.

Systems That Scale

Pick the right data structures and algorithms, run work in parallel, and ship to the cloud through a DevOps pipeline. Fast for ten users or ten million.

Products for Real People

Interview users, prototype the UI/UX, track every change in version control, and ship with a real team, starting with the Freshman Discovery Project your second semester.

Straight Answers

Questions Students Ask Us

Good questions deserve honest answers. Do not see yours? Ask BYU-Idaho AI or reach out to the CSE Department.

I Have Never Programmed. Can I Start Here?

Yes. Both majors begin with CSE 110 Introduction to Programming in your first semester. Many students write their very first program there.

Already programming? Take the Programming Placement Test (LUC). Pass it, skip CSE 110, and jump straight to CSE 111 Programming with Functions.

Why Learn to Program When Computers Can Write Code?

Because generated code is only a first draft, and someone has to know whether it is right. That takes skills no prompt replaces: User research to learn what people actually need, UI/UX design that makes software usable, system architecture that holds up under real traffic, security testing that catches vulnerabilities, and the debugging and reverse engineering it takes to fix what breaks. Our students learn the newest tools, including AI, and learn enough to direct them, check them, and stand behind the result.

Are There Still Jobs?

Yes, and the field is changing. Entry-level hiring is more competitive than it was a few years ago, so employers look for graduates who can show what they have built: Deployed apps, code they can walk through in a technical interview, team projects, and internship experience. Both majors build that portfolio with team projects, a professional readiness course, and an internship.

Do I Need to Be Good at Math?

You need to be willing to work at it. Computer Science includes calculus and discrete math, the math behind algorithms, cryptography, and machine learning. Software Engineering plans include a quantitative reasoning or statistics course and lean more on design and teamwork. In both, clear logical thinking matters more than being a “math person,” and it grows with practice.

Will I Just Sit Alone at a Computer?

Not even close. You work on teams starting in your second semester, review each other’s code, demo your work, test it with real users, and join societies that defend networks, launch cloud apps, and design a hybrid electric race car.

How Are New Tools like AI Handled in Class?

Clearly. Each instructor sets expectations for when tools like AI may be used in their course, and students are expected to do their own work and be honest about how they used any tool. Read BYU-Idaho’s guidance on academic integrity and AI use.

Skills behind the Puzzle

How This Puzzle Works and How to Build It

What You Do

You write a list of exact instructions, and the robot carries them out one at a time. A Repeat block is a loop: One instruction that runs many times.

The Ideas behind It

  • Sequencing: Computers do exactly what you say, in exactly the order you say it.
  • Loops: Repeating instructions keeps code short, readable, and easy to change.
  • Debugging: When the robot crashes, you trace the failure to one step and fix it.
  • Optimization: The shortest path and the fewest blocks are two different kinds of better. Engineers weigh both.

How This Puzzle Was Built

  • HTML: The structure of the board, the blocks, and the buttons.
  • CSS: The look and layout, with colors that stay readable at every Lights level.
  • JavaScript: The blocks you stack, the robot’s animation, and the scoring.
  • Algorithms: A breadth-first search finds the shortest path on every level, and dynamic programming works out the fewest blocks, so the star targets are always exact.

Where You Would Learn This

WDD 130 Web Fundamentals and WDD 131 Dynamic Web Fundamentals support the HTML, CSS, and JavaScript; CSE 110 and CSE 111 build the programming foundation; CSE 212 Programming with Data Structures and CSE 381 Algorithms & Complexity connect to search and optimization.

The robot only follows the plan. You made the plan.

What You Just Saw

Breadth-First Search

What the Computer Did

It checked every square one move away, then every square two moves away, then three, spreading out like a ripple until it reached the goal. Because it always checks the closest squares first, the first path it finds is guaranteed to be the shortest.

The Ideas behind It

  • Graphs: The grid is a graph. Squares are nodes, and moves are the edges between them.
  • Search Algorithms: The same idea powers map directions, network routing, and game AI.
  • Complexity: Computer scientists measure how much work an algorithm does as the problem grows, so it stays fast at scale.

Where You Would Learn This

CSE 212 Programming with Data Structures and CSE 381 Algorithms & Complexity; CSE 351 Parallelism & Concurrency helps you think about coordinating search work across concurrent branches.

The computer searched fast. A person decided what “best” means and wrote the search.

What You Just Saw

Bidirectional Search

What the Computer Did

It searched outward from the robot and the goal at the same time. When the two frontiers met, the computer had connected the two partial routes into a shortest path.

The Ideas behind It

  • Two frontiers: Each search checks the next layer from its own starting point.
  • Less work: On larger maps, meeting in the middle can explore fewer squares than searching from one end.
  • Concurrency: CSE 351 Parallelism & Concurrency explores how independent work can be coordinated safely.

Where You Would Learn This

CSE 381 Algorithms & Complexity and CSE 351 Parallelism & Concurrency.
